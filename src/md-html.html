📖 关于此工具

MD ↔ HTML 转换器 支持 Markdown 和 HTML 格式的双向转换。你可以直接编辑 Markdown 源码或可视化编辑 HTML，实时预览效果。支持图片粘贴、表格插入、代码块高亮等功能。转换结果可导出为 PDF、Word (.docx)、HTML、Markdown 和纯文本格式，满足文档编写、内容发布、技术写作等多种场景需求。

🔧 核心功能

  • Markdown→HTML：在左侧编写 Markdown，右侧实时渲染为 HTML 预览
  • HTML→Markdown：粘贴 HTML 代码，自动转换为 Markdown 格式
  • 多模板支持：内置小红书、公众号、知乎、技术文档、简历、GitHub README 等 9 套排版模板
  • 富文本编辑：支持可视化编辑，插入图片、表格、链接、代码块等
  • 多格式导出：结果可导出为 PDF、Word (.docx)、HTML、Markdown、纯文本
  • 代码高亮：支持多种编程语言的代码块语法高亮

📋 使用场景

  • 技术写作：编写技术博客、项目 README、API 文档
  • 内容发布：使用模板快速生成适合各平台（公众号/知乎/小红书）排版的文章
  • 文档导出：将 Markdown 文档导出为 PDF 或 Word 格式，方便打印和分享
  • 网页制作：用 Markdown 快速生成 HTML 页面内容
  • 个人简历：用 Markdown 编写简历，通过模板美化排版后导出 PDF

💡 使用技巧

  • 选择合适的模板可大幅提升文章排版效果，公众号推荐"公众号"模板
  • 使用 Ctrl+B/I 等快捷键可快速插入粗体/斜体等格式
  • 粘贴图片时自动转为 Base64 内嵌，无需外部图床
  • 所有编辑和转换在浏览器本地完成，内容不会上传服务器
