📖 关于此工具

文件差异对比器 支持 6 种格式对比：文本使用 Myers Diff 算法行级对比；Word (.docx) 提取文本内容对比；PDF (.pdf) 提取文字内容对比；Excel (.xlsx/.xls) 逐单元格对比；CSV 按行列对比；JSON 对比结构化数据。高亮显示新增（绿色）、删除（红色）和修改（黄色）内容。适合代码审查、文档校对、数据对比等场景。所有对比在浏览器本地完成，数据不会上传。

🔧 核心功能

  • 文本差异对比：基于 Myers Diff 算法，精确展示行级差异，新增/删除/修改分别高亮
  • Word 文档对比：上传 .docx 文件，自动提取文本内容并进行差异对比
  • PDF 文档对比：提取 PDF 中的文字内容，支持两份 PDF 的文字级对比
  • Excel 对比：支持 .xlsx/.xls 格式，逐单元格对比数据差异
  • CSV 对比：按行和列对比 CSV 文件，快速定位数据变更
  • JSON 对比：对比两份 JSON 数据的结构差异，适合 API 响应对比

📋 使用场景

  • 代码审查：对比代码版本差异，快速 review 代码变更
  • 文档校对：对比合同、报告、论文等文档的不同版本，发现修改内容
  • 数据处理：对比 Excel/CSV 数据表，检查数据更新和错误
  • API 测试：对比 API 响应数据，验证接口变更是否如预期
  • 合同审查：上传两份合同 Word 文档，快速对比条款变化

💡 使用技巧

  • 对比大文件时建议先分段对比，避免浏览器性能问题
  • Word/PDF 对比提取的是纯文本，格式差异不会被标记
  • Excel/CSV 对比以单元格为单位，注意表头对齐
  • 所有对比均在浏览器本地完成，文件不会上传到服务器，保护隐私安全
  • 支持粘贴和手动输入两种方式，灵活应对不同场景
