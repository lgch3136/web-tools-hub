📖 关于此工具

UUID 生成器 使用 crypto.getRandomValues() 生成符合 RFC 4122 标准的 UUID v4（随机 UUID）。支持批量生成（最多 1000 个），可选择标准连字符格式、无连字符、大写、花括号包裹或 Base64 编码格式。适合数据库主键、API 请求 ID、会话标识等场景。所有生成均在浏览器本地完成。

🔧 核心功能

  • UUID v4 生成：基于加密级随机数生成器，确保唯一性和不可预测性
  • 批量生成：一次生成最多 1000 个 UUID，适合批量创建测试数据
  • 多格式输出：标准（带连字符）、无连字符、大写、花括号包裹、Base64 编码五种格式
  • 一键复制：点击即可复制全部生成的 UUID
  • 实时生成：点击生成按钮立即输出，无需等待

📋 使用场景

  • 数据库主键：为数据库记录生成全局唯一标识符，避免主键冲突
  • API 请求追踪：为每个 API 请求生成唯一 ID，用于日志追踪和问题排查
  • 会话标识：生成 Session ID 或 Token，用于用户会话管理
  • 文件名：生成唯一文件名，防止上传文件重名覆盖
  • 测试数据：批量生成测试用的唯一标识符，填充测试数据库

💡 使用技巧

  • UUID v4 是随机生成的，理论上不会重复（碰撞概率约为 1/2^122）
  • 数据库中使用 UUID 而非自增 ID 可以避免暴露数据规模
  • 无连字符格式适合用作文件名，避免兼容性问题
  • 所有生成在浏览器本地完成，UUID 不会上传到服务器
