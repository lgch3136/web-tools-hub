📖 关于此工具

Base64 编解码器 支持文本和图片的 Base64 编码与解码。文本模式支持编码和解码双向操作，并可在编码/解码结果间互换。图片模式支持拖拽或点击选择图片文件，自动生成 Base64 Data URL。所有操作在浏览器本地完成，文件不会上传到服务器。常用于数据传输、图片内嵌和 API 调试。

🔧 核心功能

  • 文本 Base64 编码：将任意文本转换为 Base64 编码字符串
  • Base64 解码：将 Base64 字符串还原为原始文本
  • 编码/解码互换：一键将结果作为新输入，方便链式操作和验证
  • 图片转 Base64：支持拖拽或选择图片文件（JPEG/PNG/WebP 等），自动生成 Data URL
  • 一键复制：编码或解码结果可直接复制到剪贴板

📋 使用场景

  • 图片内嵌：将小图标或图片转为 Base64 嵌入 HTML/CSS，减少 HTTP 请求
  • API 传输：在 JSON 中传输二进制数据（如图片），通过 Base64 编码后传输
  • 数据加密：Base64 不是加密算法，但可用于简单的数据混淆（如 URL 参数）
  • 邮件附件：MIME 协议使用 Base64 编码邮件中的二进制附件
  • 数据存储：将二进制数据转为文本格式存储在数据库或配置文件中

💡 使用技巧

  • Base64 编码后的数据比原始数据大约 33%，大文件建议直接传输
  • 图片转 Base64 适合 10KB 以内的小图标，大图会使 HTML/CSS 体积膨胀
  • 使用"编码↔解码互换"功能可验证编解码是否正确
  • 所有操作在浏览器本地完成，文件不会上传到服务器
