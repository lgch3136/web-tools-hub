📖 关于此工具

开发命令速查表 收录了日常开发中最常用的命令行操作，涵盖 npm/pip 包管理、Git/GitHub CLI、Vercel 部署、Docker 容器、Linux/macOS 系统、Homebrew、SSH 远程、curl/jq HTTP 工具、Python 虚拟环境、Node.js、PM2 进程管理、Nginx、Playwright 测试、Parcel/Vite 构建、AI Agent 工具 等 15+ 类别。支持关键词搜索过滤和一键复制命令。

🔧 核心功能

  • 15+ 工具分类：按开发场景分类整理，快速定位所需工具箱
  • 关键词搜索：输入关键词实时过滤命令，快速找到目标命令
  • 一键复制：点击命令即可复制到剪贴板，直接在终端粘贴执行
  • 常用参数说明：每个命令附带参数说明，帮助理解命令含义
  • 安装命令：收录各工具的一键安装命令，方便新环境快速搭建

📋 收录工具类别

  • 包管理：npm、pip、yarn 的常用安装、卸载、更新命令
  • 版本控制：Git 分支/提交/合并/回退，GitHub CLI 的 PR/Issue/Release 操作
  • 部署运维：Vercel CLI 部署/环境变量/域名配置，Docker 容器管理
  • 系统管理：Linux/macOS 文件操作、进程管理、磁盘查看，Homebrew 包管理
  • 网络工具：SSH 远程连接/端口转发/密钥管理，curl 请求调试，jq JSON 处理
  • 开发环境：Python venv 虚拟环境，Node.js 版本管理，PM2 进程守护
  • 测试构建：Playwright 测试框架，Parcel/Vite 前端构建工具
  • AI 编程：Claude Code、Codex CLI、Hermes Agent 等 AI 编程工具

💡 使用技巧

  • 使用 Ctrl+F（Mac: Cmd+F）本页搜索可快速定位命令
  • 首次使用时建议浏览全部分类，了解收录范围
  • 将常用命令复制到个人笔记或 CheatSheet 中
  • 本页面为静态内容，无需网络即可访问（首次加载后）
