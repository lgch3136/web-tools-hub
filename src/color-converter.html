📖 关于此工具

颜色转换器 支持 HEX、RGB、HSL 三种颜色格式的互转。内置取色器可直接选取任意颜色，实时预览颜色效果并显示对应色值。提供 40+ 常用颜色面板，涵盖 Material Design 配色体系。每个色值结果均可一键复制，方便前端开发、UI 设计和品牌配色使用。

🔧 核心功能

  • HEX 颜色：支持 CSS 十六进制颜色格式（如 #FF5733），6 位和 3 位简写
  • RGB 颜色：红绿蓝三通道颜色模型，每通道 0-255 范围
  • HSL 颜色：色相（H）/饱和度（S）/亮度（L）模型，更符合人类视觉感知
  • 格式互转：在三种格式间任意切换，输入一种格式即可获得另外两种
  • 可视化取色器：内置浏览器取色器，可选取屏幕上任意颜色
  • 颜色面板：40+ 预设常用颜色，涵盖 Material Design 主题色

📋 使用场景

  • 前端开发：CSS 中频繁切换 HEX/RGB/HSL 格式，快速转换
  • UI 设计：从设计稿取色后获取对应 CSS 代码
  • 品牌配色：管理和转换品牌标准色值
  • 主题定制：调整颜色明暗度和饱和度，创建统一配色方案

💡 使用技巧

  • HSL 格式的 Lightness 设为 50% 可获得最纯正的颜色
  • 使用取色器可拾取浏览器窗口外的颜色（取决于浏览器支持）
  • 所有转换在浏览器本地完成，数据不上传
