📖 关于此工具

JSON 格式化 / 校验器 用于格式化、压缩、校验 JSON 数据。支持语法高亮预览、错误定位和自动修复（如单引号转双引号）。提供转义/反转义功能，方便在代码中嵌入 JSON 字符串。支持 Ctrl+Enter 快捷键快速格式化。内置示例数据，适合 API 调试、配置文件编辑和数据交换场景。

🔧 核心功能

  • JSON 美化：将压缩的 JSON 转换为带缩进、换行的易读格式，方便人工阅读和调试
  • JSON 压缩：移除空格和换行，将 JSON 压缩为单行，减小体积适合生产环境
  • 语法校验：实时检测 JSON 语法错误，精确定位错误位置并给出修复建议
  • 自动修复：自动将单引号转换为双引号、补全缺失的逗号和括号
  • 转义/反转义：处理 JSON 中的特殊字符转义，方便在 JavaScript/HTML 中嵌入 JSON
  • 一键复制：格式化结果可直接复制到剪贴板

📋 使用场景

  • API 开发调试：查看 API 返回的 JSON 响应，快速定位数据结构问题
  • 配置文件管理：编辑和校验 JSON 格式的配置文件（如 package.json、tsconfig.json 等）
  • 数据交换：在不同系统之间传递 JSON 数据时，确保格式正确
  • 前端开发：验证和格式化从后端或第三方接口获取的 JSON 数据
  • 数据分析：将压缩的大段 JSON 数据展开，便于分析和提取关键信息

💡 使用技巧

  • 使用 Ctrl+Enter（Mac: Cmd+Enter）快捷键快速格式化
  • 先点击"校验"检查语法，再执行"格式化"
  • 处理超大 JSON 时，建议先用压缩模式查看概览，再逐段格式化
  • 如果 JSON 来自 JavaScript 代码，可使用"单引号→双引号"自动修复
  • 格式化结果可配合浏览器的搜索功能（Ctrl+F）快速定位关键字段
