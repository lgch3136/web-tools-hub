隐私政策

生效及最后更新日期：2026年8月4日

本政策说明 Practical Tools（以下简称“本站”）在你访问网站、使用工具和阅读指南时，数据会在哪里处理、哪些信息可能被第三方接收，以及你可以怎样清理本地数据。

1. 本站直接提供的账户与数据库

本站目前不提供注册或登录功能，也没有由本站运营的用户内容数据库。你无需提交姓名、电话号码或付款信息即可使用工具。

2. 浏览器本地处理

多数工具的输入和结果只在当前浏览器标签页中计算，例如 JSON 格式化、编码转换、密码生成、Hash、字数统计和图片压缩。本站服务器不会收到这些输入内容。

仍需注意以下边界：

  • Markdown 编辑器：为了恢复草稿，会把文稿、标题和排版偏好保存到当前浏览器的 localStorage。关闭标签页不会自动删除这些草稿；请使用编辑器里的删除功能，或清理该站点的浏览器数据。
  • 汇率工具：会向 Frankfurter 或 ExchangeRate-API 请求公开汇率数据。金额换算主要在浏览器内完成，但第三方服务可看到常规网络请求信息，例如 IP 地址和 User-Agent。
  • 公共前端库：二维码和文件差异工具的部分脚本可能从 jsDelivr、cdnjs 或 SheetJS CDN 加载。CDN 可获得常规访问日志，但工具选择的本地文件不会由本站代码主动上传给这些 CDN。
  • 外部链接和图片：当文稿引用远程图片，或你主动打开外部链接时，目标服务器会收到相应网络请求。

3. 本地存储与 Cookie

本站可能在浏览器中保存以下数据：

  • Markdown 本地草稿、编辑器视图和排版偏好；
  • 语言或界面偏好；
  • Cookie/广告提示的选择记录。

这些数据位于你的设备上。你可以在浏览器的“网站数据”或“隐私与安全”设置中删除 practicaltools.xyz 的本地存储和 Cookie。删除后，本地草稿可能无法恢复。

4. 托管与基础访问日志

本站静态页面托管在 Vercel。为传输页面、保障安全和排查故障，托管及网络服务可能处理 IP 地址、请求时间、访问路径、User-Agent 和错误信息等常规日志。相关处理由服务商的政策约束，本站不使用这些日志建立用户账户画像。

5. Google AdSense

首页和工具指南等内容页面提供 Google AdSense 入口；首次访问时广告服务保持未加载状态，只有选择“同意广告 Cookie”后才会请求 Google 广告。实际是否展示广告取决于审核、地区和广告库存。纯工具操作页不包含广告入口。

  • Google 及其合作方可能使用 Cookie、本地存储或设备标识来投放、限制频次和衡量广告；
  • Google 可能处理 IP 地址、浏览器信息、页面 URL 和广告互动数据；
  • 你可以通过 Google 广告设置 管理个性化广告，并在浏览器中限制或删除第三方 Cookie；
  • 更多说明见本站的 广告声明 和 Google 广告技术政策。

6. 数据安全与使用建议

本站通过 HTTPS 提供页面，并尽量让敏感任务在浏览器本地完成，但任何在线页面和浏览器扩展都不能被描述为“绝对安全”。请不要把私钥、账户恢复词、未脱敏身份证件或其他高敏感信息粘贴到不必要的网页中。处理重要文件前，建议保留原始副本并核对导出结果。

7. 儿童隐私

本站不是专门面向 13 岁以下儿童的服务，也不要求儿童提供个人资料。如果你认为本站的实现导致了不当的数据处理，请通过下方联系方式告知。

8. 政策变更

当工具的数据流、第三方服务或广告实现发生实质变化时，我们会更新本页并修改日期。历史变更可以通过公开 GitHub 仓库的提交记录查看。
