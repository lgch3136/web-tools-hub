📖 关于此工具

强密码生成器 用于生成安全、随机、高强度的密码。支持自定义密码长度（4-64位），可选择包含大写字母、小写字母、数字和特殊符号，也可排除易混淆字符（如 O/0/I/l）。内置密码强度检测器，实时评估密码安全性。建议使用 16 位以上、包含全部字符类型的密码，并为不同账户设置不同密码。

🔧 核心功能

  • 自定义长度：支持 4-64 位密码长度，灵活满足不同网站的要求
  • 字符类型选择：可独立开关大写字母、小写字母、数字、特殊符号四种类型
  • 排除易混淆字符：自动排除 O/0/I/l/1 等容易混淆的字符，避免手动输入错误
  • 密码强度检测：实时评估密码强度（弱/中等/强/非常强），显示熵值和改进建议
  • 一键复制：生成的密码可直接复制到剪贴板

📋 使用场景

  • 账户注册：为新账户快速生成高强度密码，避免使用弱密码
  • 密码定期更新：每隔 90 天更换密码时生成新的安全密码
  • API 密钥：生成随机字符串用作开发环境中的 API Token 或 Secret Key
  • 临时密码：为访客、临时用户或测试环境生成一次性密码
  • 数据库密码：为 MySQL、PostgreSQL 等数据库生成强密码

💡 密码安全最佳实践

  • 密码长度至少 16 位，越长越安全，推荐 20 位以上
  • 同时包含大写、小写、数字、特殊符号四种类型
  • 不要重复使用同一密码，每个重要账户使用独立密码
  • 配合密码管理器（如 Bitwarden、1Password）安全存储密码
  • 本工具所有生成均在浏览器本地完成，密码不会上传到任何服务器
  • 定期检查账户是否在数据泄露事件中受影响（可访问 Have I Been Pwned）
