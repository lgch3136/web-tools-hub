📖 关于此工具

时间戳转换 支持 Unix 时间戳与日期时间之间的双向转换，同时兼容秒级（10位）和毫秒级（13位）时间戳。提供 ISO 8601、GMT、RFC 2822、本地时间等多种格式输出，点击即可复制。页面顶部实时显示当前时间及对应的 Unix 时间戳（秒/毫秒），方便开发调试和日志分析。

🔧 核心功能

  • 时间戳→日期：输入 Unix 时间戳（秒或毫秒），转换为可读的日期时间
  • 日期→时间戳：选择或输入日期时间，自动转换为 Unix 时间戳
  • 秒/毫秒双模式：自动识别 10 位秒级和 13 位毫秒级时间戳，正确转换
  • 多格式输出：提供 ISO 8601、GMT、RFC 2822、本地时间等多种常用格式
  • 实时时钟：页面顶部实时显示当前 UTC 时间、本地时间和对应的时间戳
  • 一键复制：每种格式的结果均可点击复制

📋 使用场景

  • 日志分析：将服务器日志中的时间戳转换为可读日期，快速定位问题时间
  • API 开发：调试 API 时转换请求和响应中的时间戳字段
  • 数据库查询：将数据库中的 Unix 时间戳字段转换为人类可读格式
  • 定时任务：计算 Cron 表达式对应的时间戳，配置定时任务
  • 跨时区协作：将不同时区的时间统一转换为时间戳进行对比

💡 使用技巧

  • 如果不确定时间戳是秒还是毫秒，可查看位数：10位=秒，13位=毫秒
  • Unix 时间戳基于 UTC 时区，转换为本地时间时会自动加上时区偏移
  • 时间戳 0 代表 1970年1月1日 00:00:00 UTC（Unix 纪元）
  • 所有转换在浏览器本地完成，不依赖后端服务
