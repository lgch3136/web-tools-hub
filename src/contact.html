联系与问题反馈

发现计算结果不正确、页面与说明不一致，或某项功能在你的设备上无法使用？请把可复现的信息发给我们。具体案例比笼统评价更容易转化成修复。

📬 联系方式

GitHub（推荐）

GitHub 是联系我们最直接的方式，您可以在那里：

  • 提交 Issue 报告问题或提出建议
  • 提交 Pull Request 贡献代码
  • 查看项目进展和更新日志

项目地址：https://github.com/lgch3136/web-tools-hub

邮箱

如果您更喜欢通过邮件沟通，可以发送邮件至：

lgch3136@gmail.com

该邮箱由维护者查看，但不承诺固定回复时限；公开、可复现的问题优先使用 GitHub Issue。

💡 常见反馈类型

问题报告

如果您在使用工具时遇到问题，请提供以下信息：

  • 使用的浏览器和版本
  • 操作系统
  • 问题的具体描述
  • 复现步骤（如果可能）
  • 截图（如果适用）

功能建议

如果您希望我们添加新工具或改进现有功能，请告诉我们：

  • 您希望添加什么功能或工具
  • 使用场景和需求
  • 任何参考资料或示例

内容纠错

指南中的命令、链接或兼容性说明可能随软件版本变化。请附上原文位置和可验证的新资料，便于及时修正。
