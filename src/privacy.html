隐私政策

最后更新日期：2026年5月30日

欢迎使用在线工具集（以下简称"本网站"）。我们非常重视您的隐私保护。本隐私政策旨在说明我们如何收集、使用和保护您的个人信息。

1. 信息收集

我们不收集任何个人信息。这是本网站最核心的隐私承诺：

  • 所有工具的输入数据均在您的浏览器本地处理，不会上传到我们的服务器
  • 我们不使用 Cookie 追踪您的行为
  • 我们不收集您的 IP 地址、设备信息或浏览历史
  • 我们不要求用户注册账户或提供任何个人信息

2. 数据处理

所有数据处理均在您的浏览器本地完成：

  • JSON 格式化、正则测试等文本处理工具完全在本地运行
  • 图片压缩、去水印等图片处理工具使用浏览器 Canvas API
  • Hash 计算使用浏览器内置的 Web Crypto API
  • 关闭浏览器标签页后，所有输入数据将被自动清除

3. 广告与 Cookie

本网站使用 Google AdSense 展示广告。请注意以下重要信息：

  • Google AdSense 可能会使用 Cookie 或类似技术来展示个性化广告
  • 这些 Cookie 可能会收集您的浏览行为信息，用于展示相关广告
  • 您可以访问 Google 广告设置 来管理广告偏好
  • 您也可以访问 DAA 或 EDAA 来选择退出个性化广告

我们使用的 Cookie 类型：

  • 必要 Cookie：网站正常运行所需
  • 广告 Cookie：由 Google AdSense 用于展示和衡量广告
  • 分析 Cookie：用于了解网站使用情况（如 Google Analytics，如启用）

4. 第三方服务

本网站使用以下第三方服务：

  • Google AdSense：广告服务平台，遵守 Google 广告政策
  • Vercel：网站托管服务，可能会收集基本访问日志

这些第三方服务有自己的隐私政策，建议您查阅相关条款。

5. 数据安全

虽然我们不收集您的数据，但我们仍然采取以下措施确保网站安全：

  • 使用 HTTPS 加密传输
  • 定期更新网站代码以修复安全漏洞
  • 不存储任何用户数据，从根本上杜绝数据泄露风险

6. 您的权利

如果您位于欧洲经济区 (EEA)，您享有以下数据保护权利：

  • 访问权：了解我们是否处理您的个人数据
  • 删除权：请求删除您的个人数据
  • 反对权：反对处理您的个人数据
  • 数据可携带权：以结构化格式获取您的数据

由于本网站不收集用户数据，上述权利主要适用于第三方 Cookie。您可以通过浏览器设置管理 Cookie。

7. 儿童隐私

本网站不面向 13 岁以下儿童，也不会故意收集儿童的个人信息。如果我们发现无意中收集了儿童的个人信息，将会立即删除。

8. 隐私政策更新

我们可能会不时更新本隐私政策。更新后的政策将在本页面发布，并更新"最后更新日期"。重大变更时，我们会在网站首页通知。

9. 同意条款

使用本网站即表示您同意本隐私政策。如果您不同意本政策，请停止使用本网站。
