隐私政策

最后更新日期：2026年5月30日

欢迎使用在线工具集（以下简称"本网站"）。我们非常重视您的隐私保护。本隐私政策旨在说明我们如何收集、使用和保护您的个人信息。

1. 信息收集

我们不收集任何个人信息。这是本网站最核心的隐私承诺：

  • 所有工具的输入数据均在您的浏览器本地处理，不会上传到我们的服务器
  • 我们不使用 Cookie 追踪您的行为
  • 我们不收集您的 IP 地址、设备信息或浏览历史
  • 我们不要求用户注册账户或提供任何个人信息

2. 数据处理

所有数据处理均在您的浏览器本地完成：

  • JSON 格式化、正则测试等文本处理工具完全在本地运行
  • 图片压缩、去水印等图片处理工具使用浏览器 Canvas API
  • Hash 计算使用浏览器内置的 Web Crypto API
  • 关闭浏览器标签页后，所有输入数据将被自动清除

3. 第三方服务

本网站使用以下第三方服务：

  • Google AdSense：用于展示广告。Google 可能会使用 Cookie 来提供个性化广告。您可以通过 Google 的广告设置管理您的广告偏好。
  • Vercel：用于网站托管。Vercel 可能会收集基本的访问日志用于服务维护。

4. 数据安全

虽然我们不收集您的数据，但我们仍然采取以下措施确保网站安全：

  • 使用 HTTPS 加密传输
  • 定期更新网站代码以修复安全漏洞
  • 不存储任何用户数据，从根本上杜绝数据泄露风险

5. 儿童隐私

本网站不面向 13 岁以下儿童，也不会故意收集儿童的个人信息。

6. 隐私政策更新

我们可能会不时更新本隐私政策。更新后的政策将在本页面发布，并更新"最后更新日期"。
