📚 工具使用指南

JSON 格式化工具

JSON（JavaScript Object Notation）是一种轻量级的数据交换格式。我们的 JSON 格式化工具可以帮助你：

  • 美化混乱的 JSON 代码，使其易于阅读
  • 压缩 JSON 数据，减小文件体积
  • 验证 JSON 语法是否正确
  • 支持转义和反转义特殊字符

适用场景：API 开发调试、数据处理、配置文件编辑等。

正则表达式测试器

正则表达式（Regular Expression）是处理文本的强大工具。使用我们的测试器可以：

  • 实时预览匹配结果，高亮显示匹配内容
  • 支持全局、忽略大小写、多行等多种模式
  • 内置常用正则模板：邮箱、手机号、URL 等
  • 学习和调试复杂的正则表达式

适用场景：数据验证、文本提取、批量替换、爬虫开发等。

Hash 计算器

哈希算法用于生成数据的唯一指纹。我们的 Hash 计算器支持：

  • MD5、SHA-1、SHA-256、SHA-512 多种算法
  • 文本和文件的哈希计算
  • 文件完整性校验和比对
  • 密码存储和数字签名验证

适用场景：文件校验、安全验证、数据完整性检查等。

❓ 常见问题

使用工具需要注册或付费吗？

当前无需注册账户，也没有设置付费步骤。首页和指南页可能加载广告，工具操作页不主动加载广告脚本。

工具输入会上传到服务器吗？

多数任务在浏览器本地完成。Markdown 草稿会留在当前浏览器，汇率需要请求第三方数据。不同工具的边界见隐私政策。

Markdown 草稿关闭页面后还在吗？

会。草稿保存在当前浏览器的本地存储中，直到你在编辑器中删除，或清理 practicaltools.xyz 的站点数据。

手机可以编辑和预览吗？

可以。Markdown 工作台在窄屏上改为编辑/预览切换；复杂文档和批量文件仍建议在桌面浏览器处理。
